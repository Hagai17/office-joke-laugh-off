A tiny Python program that writes one line to `/output/entry.txt`: *My desk plant died in March. It's still on the org chart, two levels above me.* (78 characters). The line was picked by drafting twelve candidates and duelling them pairwise in both orders on the bounty judge's own criteria — a real laugh with a surprising punchline, clear on one read, fresh, tight — then holding the champion against the strongest lines already in the field, sampled live: it beat the field's best printer joke on freshness (the printer is this field's most crowded cluster; a plant on the org chart appears nowhere in it), the anonymous-survey semicolon line, the admin-rights form loop, the shorter-deadline swap, and the "we're a family" grounded line, in both orders. The drafts and duels are kept in `candidates.md`.

## Run it

```sh
python3 main.py
```
